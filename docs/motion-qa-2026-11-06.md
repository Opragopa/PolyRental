# Проверка анимаций PolyRental — 06.11.2026

Проверена текущая локальная сборка, без публикации и без отправки заявок.

## Изменения

- Общие длительности: нажатие 120 мс, обратная связь и закрытие 160 мс,
  смена экрана 220 мс, календарь и переход категории 180 мс.
- Диалоги плавно появляются и исчезают. Закрывающийся диалог сразу становится
  `inert`; быстрые повторные действия не оставляют перекрытий и лишнего фокуса.
  Динамический диалог удаляется после выхода; завершение обрабатывается один раз.
- Раскрытия меняют направление с текущей высоты, без второй анимации содержимого.
  Переключение `prefers-reduced-motion` завершает активные анимации JavaScript.
- Календарь сохраняет DOM-ячейки и фокус при выборе диапазона и обновлении
  доступности. Подсветка диапазона укладывается в 220 мс вместо прежних 750 мс.
  Форматтер даты создаётся один раз на обновление, а не для каждой ячейки.
- Изменение количества сохраняет карточку и открытые подробности; в корзине
  количество обновляется без пересоздания строки. Удаление строки плавно сворачивает её.
- Ограничены повторения покачивания категорий, добавлены появления уведомлений
  и просмотра документов. Убраны переходы размера шрифта, flex и тени переключателя темы.

## Автоматические проверки

`tests/motion-qa.cjs`: 240×320, 390×844, 568×320, 1440×900 и 390×844 при CPU×4.
Проверены повторные нажатия, разворот раскрытий, удаление строки корзины,
сохранение карточек и фокуса календаря, смена месяца, открытие/закрытие/повторное
открытие диалога, динамический выход и изменение настройки уменьшения движения.
Дополнительно проверен настоящий сценарий отмены создания категории сотрудником

## Воспроизведение и артефакты

Из корня репозитория:

```powershell
$env:NODE_PATH = "$PWD/tools/browser-qa/node_modules"
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD/tools/browser-qa/.browsers"
$env:QA_LIVE_URL = 'http://127.0.0.1:8001' # необязательно, изолированный QA API
node tests/motion-qa.cjs
```

Для видео нужен FFmpeg Playwright (`node tools/browser-qa/node_modules/playwright/cli.js install ffmpeg`).
`artifacts/motion-qa/` содержит результаты JSON, видео WebM и `motion-cpu4-trace.zip`.
Трасса открывается через `playwright show-trace`; файлы артефактов исключены из Git.

Использованы механизмы CSS
[`transition-behavior`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/transition-behavior)
и [`@starting-style`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@starting-style).
В старых WebView без дискретных переходов статические диалоги сохраняют анимацию
входа и закрываются сразу; динамические диалоги используют Web Animations API.
