# 0.5.2 → 0.5.3
Что изменилось:

📝 **Добавлен запрос изменений заявки.** После подтверждения заявки и отправки анкеты клиент может нажать «Запросить изменения», пока подготовка ещё не началась. При отправке нужно указать причину.

✅ **Добавлено согласование с оператором.** До решения оператора подготовка заблокирована. При одобрении клиент исправляет даты или состав и отправляет заявку на повторное подтверждение; при отказе заявка остаётся прежней.
