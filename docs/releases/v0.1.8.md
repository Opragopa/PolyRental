# PolyRental v0.1.8

- Сохранная расписка получает устойчивый номер `SR-ГГГГ-XXXXXXXX`, построенный на уникальном ID заявки; номер одинаков при повторной генерации и не переиспользуется после удаления заявки.
- Оператор может навсегда удалить заявку из свёрнутого раздела дополнительных действий. Требуется ввести номер заявки и подтвердить действие. Удаляются данные клиента, анкета, фото, согласия, проверки, связанные ремонты и журналы заявки; остаётся только техническая запись об удалении без PII.
- Добавлен аудит факта удаления, Alembic-миграция и документ со стратегией роста: одна PostgreSQL для транзакционных данных, ограниченное хранение фото, переход на зашифрованное объектное хранилище при измеримом росте.
