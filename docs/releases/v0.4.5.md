# PolyRental 0.4.5

- Обновлено оформление клиентских и сотруднических экранов по макету: нижняя навигация, календарь, каталог, контактные поля и карточки.
- История заявок клиента отображается компактно; действия доступны после открытия заявки. Поиск по номеру запускается при вводе.
- В списке сотрудника показаны ответственный и срок обработки, в карточке — следующий шаг. Назначение выполняется выбором сотрудника.
- Сохранены действующие правила выдачи и возврата 0.4.4: отдельная отметка доверенного подписанта для них не требуется.
- Версия обновляет URL статических ресурсов для сброса кеша. Миграции базы данных и изменения серверных правил не добавлены.

Макет сотруднических сценариев остаётся частично прототипом; это обновление не заявляет полного переноса всех его состояний.
