# PolyRental v0.1.6

- Акты и сохранная расписка загружаются через штатный Telegram `downloadFile`, вместо перехода Mini App на временный `blob:` URL, который мог приводить к чёрному экрану в iOS WebView.
- Выдача документа использует одноразовую ссылку сроком на 2 минуты. Ссылка создаётся только для авторизованного сотрудника с доступом к персональным данным; URL загрузки не записывается в access logs.
- Ответ содержит `Content-Disposition`, `Cache-Control: no-store` и CORS-заголовок, требуемый загрузчиком Telegram. Для старых Telegram-клиентов и браузера оставлен резервный путь; `blob:` URL теперь отзывается с задержкой.
- В `ROADMAP.md` оставлена ручная проверка на реальных iOS/Android-клиентах.
