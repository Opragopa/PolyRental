# PolyRental v0.1.3

Исправлена повторная отправка анкеты после запроса коррекции.

- Поля версии согласия при повторной отправке необязательны; при первой подаче сервер по-прежнему проверяет согласие и его хэш.
- Ответ статуса анкеты включает только типы уже сохранённых документов. Форма сообщает, что фото сохранены и их не нужно загружать повторно.
- Если оператор попросил заменить определённое фото, форма отдельно показывает это требование и ждёт новый файл для указанного документа.

Проверка включает сценарий: отправить анкету с тремя фото, запросить исправление ФИО, повторно отправить без фото и полей согласия; поля сохраняются, фотографии остаются приложенными. Полный набор: **66 passed**, одно предупреждение Starlette/AnyIO.
