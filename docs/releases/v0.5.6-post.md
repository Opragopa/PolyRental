# 0.5.5 → 0.5.6
Что изменилось:

🛒 **Ограничено количество оборудования.** Нельзя добавить больше пригодных экземпляров, чем есть в каталоге. После проверки дат количество ограничено свободным остатком на выбранный срок.

📄 **Перенесён импорт CSV.** В управлении каталогом кнопка «Импорт CSV» находится наверху рядом с настройками. Шаблон и загрузка файла открываются в отдельном окне.

📋 **Убрано масштабирование фильтров заявок.** На телефоне фильтры «Все», «Нужна проверка», «К выдаче» и «К возврату» размещены в две колонки. При выборе кнопки сохраняют размер.
