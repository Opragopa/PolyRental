# PolyRental v0.2

## Управление заявками

- После досрочного возврата оператор может пометить заявку отменённой. Факт возврата, архив документов и 90-дневный срок хранения анкеты сохраняются; буфер оборудования после возврата продолжает действовать.
- Основные кнопки в панели оператора стали компактнее.
- Фото документов анкеты и сформированные акт с распиской теперь находятся в сворачиваемых списках.
