# PolyRental 0.4.2

- Готовую заявку можно вернуть в подготовку прямо из проверки анкеты. После исправления потребуется новая расписка.
- Обращения назначаются сотрудникам с доступом к персональным данным и закрываются после доставки ответа клиенту.
- Подтверждение бумажной подписи показывается только доверенным сотрудникам.
