# PolyRental v0.1.9

- Исправлено продолжение операторских этапов: в комплектовании и проверке возврата отображается кнопка «Далее», а доступность перехода сопровождается подсказкой по обязательным проверкам.
- Для создания заявок установлен минимальный срок: дата выдачи должна быть позже даты «сегодня + 3 дня». Ограничение видно в календаре и проверяется сервером для Mini App и бота.
- При создании новой анкеты клиенту предлагаются реквизиты из последней анкеты в пределах срока хранения. Фотографии не переносятся, согласие запрашивается отдельно для каждой заявки.
- Исправлена сохранная расписка: контакт не получает лишний плюс, паспорт печатается один раз, дата привязана к подписанию или формированию документа, ФИО берётся из проверенной анкеты.

Перед выпуском проверены синтаксис Python/JavaScript и чистота `git diff --check`. Полный набор тестов не запускался.
