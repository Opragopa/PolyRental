# PolyRental v0.1.1

Патч к v0.1: встроенный выбор полей, которые клиенту нужно исправить, и временное сохранение фото документов на устройстве.

- Вместо системного окна Telegram показывает адаптивную форму с понятными названиями полей и комментарием для клиента.
- Ошибки API с подробностями в формате FastAPI теперь показывают причину вместо общего сообщения.
- Выбранные фото сохраняются в IndexedDB этого устройства на срок до 24 часов и восстанавливаются при повторном открытии анкеты. После успешной отправки черновики удаляются.
- Если оператор попросил заменить конкретную фотографию, клиент должен выбрать новый файл для этой фотографии. Остальные ранее отправленные фото сервер сохраняет.

Пользователь видит срок и место локального хранения перед выбором документов. Фото остаются в локальном хранилище браузера до успешной отправки и очищаются после неё; персональные поля анкеты в локальный черновик не записываются.
