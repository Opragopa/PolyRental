# Политех.АРЕНДА v0.2.5

- Убрана отдельная кнопка захвата этапа в карточке оператора. Этап блокируется автоматически при действии; имя занятого оператора по-прежнему видно.
- Поля времени выдачи и возврата стали компактнее на первом шаге бронирования.
- Имя для заявки и телефон или Telegram сохраняются для следующего бронирования отдельно от анкеты с ФИО. При отсутствии данных на устройстве берутся контакты из последней заявки пользователя.
