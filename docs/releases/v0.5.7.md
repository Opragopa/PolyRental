# 0.5.7 — 9 ноября 2026

Исправлены две причины проблем с фото внутри заявки. Ответы API заявки содержат article_media с публичными данными модели и актуальным фото, по одному экземпляру превью на модель. Состав заявки и осмотр экземпляров используют эти данные, не требуя предварительного открытия каталога. Для клиентов передаются только данные моделей из состава заявки; служебные номера экземпляров не добавляются. При замене или удалении фото следующий запрос получает актуальный результат.

Внутренний блок request-item-media заполняет рамку request-equipment-thumb по ширине и высоте. Прежние 56×56 px внутри 42×42 px обрезали изображение и смещали его визуальный центр вниз и вправо. Пропорции изображения сохраняются через object-fit:contain. Индикатор загрузки и повтор при ошибке из hotfix-6 продолжают работать.

Проверки: API заявки без открытия каталога, актуальность замены/удаления фото; браузерные проверки состава заявки и осмотра при подготовке/возврате на 320, 390 и 1440 px с измерением центра и размеров рамки.

Миграций и новых переменных окружения нет. В приложении подготовлено описание версии 0.5.7.

Автопубликация 0.5.7 в релизном образе отключена через channel_announcement:false; описание доступно внутри приложения. После явного подтверждения пользователя 10.11.2026 выполнена разовая публикация через штатный publisher: [пост №25](https://t.me/PolyRental_channel/25), sent, одна попытка. Исходники и образы production не менялись.
