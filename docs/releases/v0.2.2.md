# PolyRental v0.2.2

## Подписка Google Calendar

- Исправлена ссылка календаря для токенов с символами `/`, `+`, `%` и `=`: секрет передаётся в query-параметре.
- Обновлена конфигурация Nginx: URL защищённой ленты и legacy-ссылки исключены из access log.
- Лента показывает подтверждённые брони, арендуемое оборудование и фактическое время раннего возврата; отменённые события получают статус отмены.
