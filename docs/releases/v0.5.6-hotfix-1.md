# 0.5.6-hotfix-1 — 9 ноября 2026

Можно выбрать занятые экземпляры, максимум — общее количество пригодных экземпляров модели (и прежний предел 30). Например, при двух камерах и одной свободной выбираются две; на проверке срока показывается нехватка и автоматически предлагается ближайший период для всей подборки в нужном количестве.

Количество не уменьшается автоматически. Изменение количества в сводке сверх свободного остатка возвращает к срокам с сохранённой подборкой. Перед отправкой доступность обязательно проверяется; выбор не является резервом.

Миграций и переменных окружения нет. Используется объявление 0.5.6, отдельного сообщения в канал для hotfix нет.
