# 0.4.7 — предпросмотр расписок

В Telegram на iPhone окно PDF-расписки могло оставаться пустым: приложение использовало встроенный PDF-просмотрщик через iframe. Теперь PDF.js отображает страницы внутри Mini App. Библиотека, worker, шрифты и WASM размещены вместе с приложением; документы не передаются внешним сервисам. При закрытии освобождаются worker и canvas. Скачивание исходного PDF остаётся доступным, ошибки загрузки показываются текстом.

Новые расписки по-прежнему создаются в DOCX. Исправлены имя файла защищённой ссылки и чтение исторических DOCX, сохранённых до появления метаданных выдачи. История показывает доступность таких документов. Срок хранения считается от даты оригинала; чтение проверяет SHA-256. Существующие файлы не перегенерируются.

Включено ранее подготовленное удаление кнопок быстрого выбора длительности бронирования. VoiceOver исключён из текущего прохода по решению пользователя.

Проверки: API для старого DOCX, срока хранения и одноразовой загрузки; браузерные проверки клиента и сотрудника в Chromium/WebKit, многостраничного PDF, очистки и ошибок. Оригинал PDF заявки №0006 проверен в памяти: SHA-256 совпадает, страницы отображаются в Chrome и WebKit. Результат на физическом iPhone после исправления пока не подтверждён.

Проверка рабочей очереди 2026-11-01: Telegram принял 20 уведомлений и 21 доставку карточек, ошибок и дублей нет, уведомлений автору действия нет. Семь карточек имеют message_id. Ожидающие доставки отложены тихими часами до 2026-11-02 08:00 МСК; просроченных нет. Это подтверждение ответов Telegram API, а не прочтения пользователями.
