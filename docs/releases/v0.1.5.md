# PolyRental v0.1.5

- Проверка комплекта сгруппирована: одна кнопка отмечает все оставшиеся экземпляры исправными, а неисправность указывается отдельно для конкретного экземпляра.
- Каждая строка проверки показывает модель и серийный номер; рядом виден прогресс по комплекту.
- Кнопки «Заказ готов» и «Завершить возврат» недоступны, пока проверки не завершены.
- Успешная отметка исправности обновляет строку на месте, не перерисовывая список и не сбрасывая прокрутку. После других обновлений экрана позиция прокрутки сохраняется.
