# 0.5.7 → 0.5.12
Что изменилось:

🗂 **Каталог можно смотреть списком или плиткой.** Поиск сохраняется при переходах между категориями. В управлении можно переименовать категории и загрузить для них фото.

🎞 **Переходы между экранами стали короче.** Категории, карточки и корзина открываются с плавными переходами. Приложение учитывает настройку уменьшения движения.

🔔 **Уведомления собраны в отдельной панели.** В ней видны события по заявкам, время и отметки о прочтении.

📋 **Следующий шаг по заявке виден сразу.** Активные заявки находятся над каталогом. Когда комплект готов, приложение и Telegram подсказывают согласованное время получения.

👤 **Имя и телефон заполняются в анкете.** Заявку можно отправить без повторного ввода этих данных. В профиле анкета раскрывается по нажатию. При оформлении можно указать цель аренды, если администратор включил этот вопрос.

📦 **Выдачу и приёмку фиксирует сотрудник.** Начать сдачу можно из главного меню. Сотрудник также может открыть приёмку, если техника уже возвращена, а клиент ещё не поставил отметку.

🛠 **Состав заявки можно изменить до выдачи.** Оператор может добавить позиции после планового начала аренды. После сохранения заявка ждёт отдельного подтверждения оператора.

📅 **Занятость вне сервиса открывается из карточки модели.** Кнопка находится рядом с «Подробнее». Если экземпляров несколько, можно выбрать нужный.

📷 **Ошибки загрузки фото видны в окне категории.** Сообщение выделено красным. Название и выбранный файл сохраняются для повторной попытки.
