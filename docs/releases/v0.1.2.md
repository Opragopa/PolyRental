# PolyRental v0.1.2

Обновлена анкета для договора.

- Номер студенческого принимается только как 8 цифр; клиент и API показывают ошибку у самого поля.
- Ошибки анкеты и фотографий возвращаются API вместе с идентификатором поля и отображаются рядом с ним.
- Для вуза доступен поисковый каталог Санкт-Петербурга. Каталог составлен по материалам [городского Комитета по науке и высшей школе](https://www.gov.spb.ru/gov/otrasl/c_science/information/) и портала [StudyInSPB](https://studyinspb.ru/). Старое значение вуза в анкете сохраняется при её исправлении.
- Адрес регистрации получает подсказки DaData через авторизованный серверный endpoint. Значение `DADATA_API_KEY` хранится только в серверном `.env`; ввод адреса в любом случае остаётся доступен вручную. До вызова подсказок пользователь видит уведомление о передаче текста DaData.

Проверки перед выкладкой: **65 passed**, одно предупреждение о deprecated alias в Starlette/AnyIO. Проверены 8-значный номер, ошибки с привязкой к полю/фото, авторизация и резервный ручной ввод при недоступном ключе DaData.

После выкладки `/health` вернул `version: 0.1.2`; HTML, JS и CSS доступны по HTTPS. Публичный авторизованный запрос к DaData вернул HTTP 200 и семь подсказок. Ключ задан в серверном `.env`, его значение не включено в репозиторий или браузер.
