# PolyRental v0.1

Опубликовано 26 октября 2026 года, МСК.

- Бот: [@PolyRental_bot](https://t.me/PolyRental_bot), кнопка меню «Забронировать».
- Mini App: [открыть приложение](https://polyrental.cloudopragopa.online/miniapp).
- [Проверка версии сервера](https://polyrental.cloudopragopa.online/health): `{"status":"ok","version":"0.1"}`.

Версия хранится в корневом `VERSION`. Сервер подставляет её в HTML: метаданные, видимую отметку `v0.1` рядом с названием, а также URL JS и CSS. HTML выдаётся с `Cache-Control: no-store`, чтобы повторный запуск в Telegram получал актуальную сборку. QA-входы используют ту же версию.

Выпуск включает исправления совместимости MainButton, резервный UUID для HTTP в тестовом Telegram, проверки авторизации и локальные средства QA. Подробнее о предыдущем проходе: [отчёт об отладке](../telegram-debug-report.md).

## Выкладка и проверка

Пересобраны и пересозданы рабочие `miniapp` и `bot` через `compose.yaml` + `compose.miniapp.yaml`. Сохранён существующий Windows Nginx, который уже обслуживает домен по HTTPS; отдельный Compose Nginx не запускался. `PUBLIC_URL` в локальном `.env` изменён на `https://polyrental.cloudopragopa.online`, `TELEGRAM_TEST_ENVIRONMENT=0`. Секреты и `.env` в Git не включаются.

Подтверждено после выкладки:

- Публичный HTTPS проходит обычную проверку сертификата.
- `/health` возвращает версию `0.1`.
- `/miniapp` содержит видимую версию `v0.1`, не содержит незаполненных маркеров и mock SDK.
- JS/CSS по URL с `?v=0.1` совпадают с исходниками по SHA-256.
- API без Telegram-подписи возвращает `401`.
- Реальный Bot API возвращает кнопку меню «Забронировать» с публичным HTTPS URL; клавиатура бота формирует тот же URL.
- Оба рабочих контейнера запущены без перезапусков.

Перед выкладкой: **59 passed**, одно предупреждение Starlette/AnyIO. Две новые проверки подтверждают согласованность `/health`, версии в HTML и доступности JS/CSS в обоих HTTP-приложениях.

Проверка выполнялась через публичный HTTPS и реальный Bot API. Полный пользовательский сценарий внутри Android/iOS Telegram этим проходом не подтверждён. При уже открытом старом окне Mini App закройте его и снова нажмите «Забронировать» в меню бота.
