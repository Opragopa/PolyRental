# PolyRental 0.4.4

- Клиент по-прежнему подтверждает получение и сдачу оборудования в Mini App.
- Выдачу после подтверждения клиента оформляет текущий сотрудник. Отдельный признак доверенного подписанта и отметка бумажной подписи для этого больше не требуются.
- Возврат завершается после подтверждения клиента и проверки оборудования. При выдаче и завершении возврата сохраняются Telegram ID и отображаемое имя фактического сотрудника.
- В новых распечатках есть поля для ручного указания сотрудников; ранее сохранённые расписки остаются неизменными.
- Закрепление подготовки и действующая временная блокировка обработки сохраняются; выдачу и завершение возврата может выполнить другой сотрудник, если этап не занят.
