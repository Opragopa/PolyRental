# PolyRental — права сотрудников v0.4

`ADMIN_IDS` допускает к служебным операциям, хранимая `StaffRole` определяет действие. Иерархия: admin → manager → operator. Пустая/неизвестная подроль не даёт полномочий. `PII_ADMIN_IDS` — независимый доступ, не наследуемый административной ролью.

| Действие | Минимальная роль / условие |
|---|---|
| Подтверждение и отмена заявки | operator; статусные ограничения |
| Изменение с ответом клиента, отклонение с причиной, передача заявки | manager |
| Подготовка, проверки, выдача и приём | operator; закрепление и актуальное состояние |
| Каталог, ремонт, скрытие заявки/строк/экземпляров | operator; статусные ограничения |
| Восстановление, тестовые флаги, исправление/удаление особенностей | admin |
| Владелец/контакт и внешняя занятость | manager |
| Добавление особенности | operator; старые записи не меняются |
| Роли и доверенные подписанты | admin; ID присутствует в ADMIN_IDS; собственную роль администратора понизить нельзя |
| Отдельная отметка бумажной подписи (совместимость) | operator или выше + TrustedSigner; с 0.4.4 не обязательное условие выдачи/завершения |
| Создание категорий | operator или выше |
| Полные ПД, фотографии, вердикты и документы сотрудника | PII_ADMIN_IDS независимо от подроли |
| Собственная расписка DOCX / исторический PDF и ответ на изменения | проверенный владелец заявки |

Неоднозначные права старых требований сохранены по прежнему служебному доступу для каталога/скрытия и ограничены менеджером для нового владельца/внешней занятости. Это конкретные правила реализации для приёмки, а не расширение PII-доступа.

При подготовке заявка закрепляется за сотрудником до закрытия или явной передачи менеджером. 10-минутный лок сериализует действия и не снимает назначение по истечении. Менеджер/администратор может вернуть на доработку по матрице; оператор — свою подготовку/готовность. Проверка анкеты и бумажная подпись используют отдельные операции: доверенный подписант может отличаться от фактического оператора.

ID только из PII-списка получает ревью и исторические документы без складских действий, каталога или управления ролями. Для исправления анкеты готовой заявки есть ограниченный возврат `ready → preparing`. Общая история содержит только событие, ID и время. Приватный комментарий доработки доступен владельцу заявки, автору с действующей подролью и PII-проверяющему.

Уточнено для 0.4.6: фактические действия сотрудников доступны круглосуточно; календарь ограничивает плановые даты. Подготовлено локально, не является подтверждением выпуска.

Миграция 27 первоначально назначает admin существующим ADMIN_IDS. Новые ID добавляются в конфигурацию и получают роль через «Сотрудники». Список доверенных по умолчанию пуст: администратор указывает реальное ФИО подписанта и активность. Изменение роли не изменяет PII-список и не переписывает прежние подписи.
