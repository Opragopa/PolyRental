`https://polyrental.opragopa.com` содержал `Bot domain invalid`, а для
старого домена возвращал виджет. Страница сайта уже передавала правильные
`PolyRental_bot` и callback нового домена.

BotFather. Повторная проверка нового origin: ошибки нет, Telegram

открытую ранее страницу входа нужно обновить.
