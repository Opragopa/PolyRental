# Панель уведомлений — 16.11.2026

За основу выбран пользователем первый референс: [Notifications Dropdown — Jeremy Blaze](https://dribbble.com/shots/25395124-Notifications-Dropdown). Применены компактные строки с небольшими нейтральными иконками, заголовком события, описанием и приглушённым временем. Палитра и шрифт сохранены из PolyRental.

Крупная кнопка закрытия заменена крестиком в шапке с областью нажатия 44×44 px. Список прокручивается отдельно от шапки. Пагинация показана только при наличии следующих записей; ошибка загрузки имеет отдельное действие повтора. Сохранены закрытие Escape, возврат фокуса и существующий механизм прочтения.

API inbox дополнен полями `title`, `summary`, `kind`. Исходное `message` и сохранённые сообщения не меняются. Представление исключает строки атрибуции и текст ссылки из Telegram; для старых полных карточек оставляет номер и статус заявки. Отдельная миграция не требуется.

Проверено:

- 5 серверных тестов: приватность inbox, прочтение, пагинация, поддержка, компактное представление зашифрованных и старых сообщений, версии ресурсов.
- `notification-panel-ui.cjs` и `category-navigation-ui.cjs` прошли в Chromium и WebKit. Покрыты ширины 320/390/1440 px, светлая и тёмная темы, длинный список, положение крестика, пустое состояние, ошибка с повтором, следующая страница, прочтение и возврат фокуса.
- Снимки мобильной светлой и настольной тёмной панели просмотрены визуально. Предпросмотр: `artifacts/notification-panel/preview.png`.
- Проверки синтаксиса JS/Python и `git diff --check` прошли.

Обновлена только среда `polyrental-acceptance` штатным скриптом проверки изоляции. Бот и Mini App работают, БД healthy. `/health` отвечает 200, новый заголовок панели присутствует в HTML через локальный порт и `https://testing.cloudopragopa.online/miniapp`.
