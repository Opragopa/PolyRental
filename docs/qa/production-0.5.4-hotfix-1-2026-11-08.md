## Откат

Из корня проекта:

```powershell
docker compose -p polyrental -f compose.yaml -f compose.miniapp.yaml -f tmp/release-054-hotfix-1/compose.rollback.json up -d --no-deps --no-build --pull never bot miniapp
```

Rollback возвращает оба сервиса на `polyrental-release:0.5.4-02c555d25c0b`. Файлы release/rollback, сверка окружения и скрипты smoke находятся в игнорируемом `tmp/release-054-hotfix-1`. Данные и журнал публикаций сохранять.

Полный вход реальным Telegram-аккаунтом и ручная проверка на физических Telegram iOS/Android/Desktop в этот выпуск не входят; headless WebKit не заменяет их.
