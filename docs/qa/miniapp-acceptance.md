# Единый чек-лист приёмки Telegram Mini App

Редакция: 01.11.2026. Продукт: PolyRental 0.4.7. Этот документ объединяет критерии приёмки из [требований](../../requirements.md), [ролей](../design/roles.md) и [стратегии тестирования](../testing-strategy.md). Он не добавляет новые бизнес-функции. При изменении правила сначала обновляются требования, затем соответствующий критерий здесь.

## Что именно проверяется

- Production 0.4.7: [протокол выпуска](production-0.4.7-2026-11-01.md). Предыдущий выпуск: [0.4.6](production-0.4.6-2026-11-01.md).
- Последний проверенный CI: [835df33](https://github.com/Opragopa/PolyRental/actions/runs/41338683711): Test (включая проверку восстановления), Mobile UI Chromium/WebKit и Local document robustness PASS. Автодеплой отключён, выпуск выполнен локально. Серверный набор — 257 тестов.
- Исправление ФТ-UI-08, удаляющее быстрые сроки, проверено в Chrome/WebKit и развёрнуто в 0.4.7. Серверный набор 0.4.7: 257 PASS; новый предпросмотр и завершение заявки проверены в Linux Chromium/WebKit.
- Браузерная эмуляция, API-тесты, production smoke и физические устройства — разные уровни доказательств. Успех одного не заполняет остальные автоматически.

Статусы: **PASS** — результат подтверждён указанным доказательством; **FAIL** — воспроизведено нарушение; **NOT RUN** — ещё не проверялось; **BLOCKED** — проверку нельзя выполнить, указана конкретная причина. Частичный результат не обозначается PASS: следует перечислить пройденные случаи и остаток.

## Требования платформы и решения проекта

Telegram предписывает проверять полученные данные авторизации и предоставляет API тем, видимой области, безопасных отступов и нативных кнопок. Рекомендации Telegram по дизайну включают адаптивность, доступные подписи и соответствие теме. Источник: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), разделы Initializing Mini Apps, Validating Data и Design Guidelines, сверено 01.11.2026.

Ширины 320/390/440 CSS px, область касания 44×44 CSS px и следующие правила приёмки — конкретизация требований PolyRental. Размер 1320×2868 при плотности ×3 соответствует 440×956 CSS px; это контрольный экран, а не стандарт платформы. Размер физического снимка не доказывает доступность интерфейса с открытой клавиатурой.

## Как проводить проверку на устройстве

1. Записать commit/версию приложения, модель устройства, ОС, версию Telegram, способ запуска, тему и масштаб текста. Проверять код одной версии, закрыв старое окно Mini App перед запуском.
2. Для реальной отправки, фото, выдачи и отмены использовать отдельную QA-среду и тестовые данные/аккаунты. В production без подготовки пройти только просмотр и черновик, не отправляя заявку. Не использовать настоящие паспорта как тестовый материал.
3. Пройти [сценарий iPhone](miniapp-device-session-2026-11-01.md). Повторить на Android и Desktop, особенно SDK-кнопки и скачивание.
4. Для каждого пункта записать PASS/FAIL/BLOCKED/NOT RUN, точные шаги, результат и доказательство. В снимках и записях не сохранять документы, initData, токены и контакты третьих лиц.
5. Для уведомлений использовать двух участников; отдельно проверить автора, ответственного, передачу и отключённые напоминания. Записать время действия и получения; не считать getMe доказательством доставки.

## Решение о приёмке

Блокируют функциональную приёмку: обход доступа/утечка ПД, дубли заявки, неверное резервирование, потеря документа/данных, невозможность основного пути на поддерживаемом устройстве. Не пройденный тест означает отсутствие подтверждения, а не автоматическое наличие дефекта.

Финальный акт требует: обязательные критерии без FAIL; заполненные матрицы реальных iOS/Android/Desktop; протокол 3–5 наблюдаемых сессий; ссылки на CI конкретного SHA. Сейчас итоговая приёмка **не завершена**. Минимальные версии ОС/Telegram, числовой бюджет производительности и полное WCAG-соответствие не установлены; не выдавать их за согласованные гарантии.

Backlog IDEA-01/02/03 и детализация Figma DESIGN-01 не становятся условиями существующих функций автоматически. Эксплуатационные OPS-01 и организационные ORG-01 остаются самостоятельными целями.
