# Соответствие функций Mini App и текстового бота

Проверено по маршрутам `app/miniapp.py` и обработчикам `app/bot.py`, `app/chat_workflows.py`. Статус «защищённая форма» означает переход из чата; это не текстовая реализация.

| Функция | Текстовый бот |
|---|---|
| Бронирование, поиск и количество | Реализовано; требуется сквозная проверка на устройствах |
| Список заявок клиента, страницы, карточка, отмена | Реализованы список, карточка, отмена и исправление ожидающей заявки; требуется проверка на устройствах |
| Принятие предложенных изменений | Принятие, оспаривание и исправление по запросу менеджера реализованы в чате; нужна проверка на устройствах |
| Подтверждение получения и возврата | Получение, возврат и подтверждение частичной выдачи с постраничным перечнем реализованы; примечания к исключениям — в защищённой заявке, нужна проверка на устройствах |
| Анкета, фотографии и просмотр документов | Защищённая форма Mini App |
| Расписка | Защищённая форма Mini App |
| Напоминания клиента | Включение и отключение реализованы; обязательные сообщения не отключаются |
| Обращение в поддержку | Создание, список и статусы для клиента; для сотрудников очередь, назначение, закрытие и ответ по команде, текст обращения — в защищённой форме; нужна проверка на устройствах |
| Очередь сотрудников, карточка, поиск, страницы | Реализованы очередь, страницы, карточка, поиск, передача ответственному, запрос исправления, отклонение и возврат на доработку; требуется проверка на устройствах |
| Изменение состава и сроков оператором | Пошаговый сценарий менеджера с поиском, подтверждением и проверкой актуальности; требуется сквозная проверка |
| Назначение техники и проверки | Реализованы автоматическое и ручное назначение, частичная комплектация с заменами, проверка комплекта и фиксация неисправности; фото повреждения при возврате загружается в чате, нужна сквозная проверка |
| Выдача и возврат сотрудником | Переходы и фиксация результатов возврата реализованы с существующими проверками; требуется проверка на устройствах |
| Каталог, экземпляры, зависимости и импорт | Поиск, создание и редактирование моделей и экземпляров, категории, фото модели, удаление экземпляров, связи и CSV-импорт реализованы; операции владельцев, занятости и особенностей экземпляров реализованы; нужна сквозная проверка на устройствах |
| Ремонт, поддержка и настройки сотрудников | Поиск и закрытие ремонтов, управление обращениями, тихие часы, роли и доверенные подписанты реализованы; прочие настройки требуют сверки |
| Тестовые заявки и доступ клиента | Тестовые отметки, скрытие и восстановление заявок, ограничение бронирования реализованы; требуется проверка на устройствах |
| Удаление и восстановление | Заявку, позицию и назначенный экземпляр можно удалить в чате с подтверждением и возможностью отмены; администратор восстанавливает удалённое через `/deleted`. Проверены автоматические сценарии, нужна приёмка в Telegram |
| Роли и защищённый доступ | Настройка ролей и подписантов в чате реализована с ограничением по ADMIN_IDS; доступ к ПД назначается отдельно, нужна полная проверка сценариев |

Реальные Telegram iOS / Android / Desktop, авторизация сайта на рабочем домене и получение уведомлений требуют отдельной приёмки. Таблица фиксирует оставшуюся работу и не подтверждает полное соответствие.
