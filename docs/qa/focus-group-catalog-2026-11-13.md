# Каталог для фокус-группы

13.11.2026 по запросу пользователя в отдельную базу `polyrental_acceptance` добавлен каталог основной базы. Пользователь выбрал только каталог, оборудование и особенности.

Источник читался в транзакции `REPEATABLE READ READ ONLY`. Перенесены 53 модели (включая 7 архивных), 86 экземпляров, 14 фотографий и настройки 12 категорий. Отдельных актуальных особенностей и зависимостей в источнике нет. Описания и комплектация перенесены с моделями. Модели сопоставлены по SKU, экземпляры — по внутреннему инвентарному номеру, связи получили новые тестовые ID.

Клиенты, контакты владельцев, анкеты, документы, заявки, расписания, права сотрудников, журналы и очереди уведомлений не экспортировались. Запись в основную базу не выполнялась. Текущие тестовые записи сохранены: после импорта 57 моделей, 93 экземпляра, 15 фотографий, 2 особенности, 5 заявок.

Проверки: предварительный импорт с откатом, успешная единая транзакция, побайтовое сравнение перенесённых фотографий, повторный импорт с откатом без добавления дублей. API тестового приложения возвращает 50 доступных к показу моделей, фотографии и health `ok`, версия 0.5.11. Архивные модели сохраняют архивный статус.

Снимок разрешённых данных и резервная копия тестовой базы до переноса находятся в игнорируемой папке `artifacts/focus-group/`. Резервная копия: `acceptance-before-20261113T082740Z.dump`.

Скрипты: `scripts/copy_catalog_to_acceptance.py` (без флага — проверка с откатом, `--apply` — резервная копия и перенос), `scripts/import_acceptance_catalog.py` (запрещает другую целевую базу).
