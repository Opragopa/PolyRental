# Production 0.5.2-hotfix-2 — отображаемые имена

05.11.2026: установлен `polyrental-release:0.5.2-hotfix-2-3ddce91d9ccd`.

## Поведение

- В истории заявок, назначениях, списках сотрудников, поддержке, закреплении
  обработки, выдаче/приёмке и новых уведомлениях Telegram ID заменены именем
  или @ником. Если имя недоступно, показывается «Сотрудник»/«Пользователь»;
  системные действия подписаны «Система».
- Публичное имя из подтверждённых Telegram-данных обновляется в профиле
  при входе/запросе API и сообщении/нажатии кнопки бота. Старые записи
  разрешают имена при чтении без переписывания аудита и архива выдачи.
  Паспортные анкеты не используются как источник отображаемых имён.
- Внутренние идентификаторы, сравнения владельцев, права доступа и значения
  действий сохранены. История API дополнена `actor_name`/`target_name`,
  поддержка — именами владельцев/клиента и списком `eligible_staff`.
- Добавлена совместимая миграция `20261105_42`: поле
  `client_profiles.display_name`. Локальная и production БД обновлены.
