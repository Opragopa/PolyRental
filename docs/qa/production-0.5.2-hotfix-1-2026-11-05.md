# Production 0.5.2-hotfix-1 — 05.11.2026

- Hotfix выложен по запросу пользователя на удобный ввод времени с клавиатуры компьютера. Бот и Mini App работают на `polyrental-release:0.5.2-hotfix-1-a8059d4dc91c`. Окружение сверено с прежними контейнерами: отличий нет. PostgreSQL, Redis и Nginx не пересоздавались, миграции не запускались. Git commit/push не выполнялись.
- На устройствах с мышью и точным указателем поля времени бронирования становятся обычными текстовыми полями с подсказкой. Принимаются `09:30`, `9:30`, `0930`, `930`, `9.30`, `9 30`, а также час `9` (09:00). При Tab/Enter значение приводится к `ЧЧ:ММ`. При фокусе значение выделяется для замены; Enter переводит фокус к возврату, затем к кнопке проверки заявки. На телефонах остаётся нативный `input[type=time]`.
- Часы вне 00–23, минуты вне 00–59 и неполный/посторонний ввод не записываются в скрытый период и не отправляются в календарь доступности. Ошибка видна рядом с полем после завершения ввода. Пустое время по-прежнему обязательно; ограничения рабочих часов и дат сохраняются. Нормализованный период используется в проверке, экране подтверждения и сохранённом черновике.
